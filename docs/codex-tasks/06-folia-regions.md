# Codex-Aufgabe 6: Folia Regions-TPS

Implementiere einen vom allgemeinen Paper-Code isolierten Folia-Provider, eine
belastbare Plattform- oder Feature-Erkennung über öffentliche APIs, eine
RegionObservationRegistry und aggregierte TPS-Verteilungen pro Welt.
Spielerpositionen dürfen intern als Messquelle dienen, aber keine Spieleridentität
darf gespeichert oder exportiert werden. Interne Folia-Klassen, NMS und Reflection
auf Plattforminternas bleiben verboten.
