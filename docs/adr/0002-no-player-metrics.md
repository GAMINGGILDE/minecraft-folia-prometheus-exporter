# ADR 0002: Keine individuellen Spielermetriken

## Entscheidung

Das Plugin exportiert keine individuellen Spielermetriken oder Spielerstatistiken.

## Konsequenzen

- keine Spielernamen oder UUIDs als Label
- keine Spielerpositionen
- keine individuellen Statistiken
- keine individuellen TPS-Zuordnungen
- ausschließlich aggregierte Spielerwerte
- zukünftige Beiträge mit personenbezogenen Metriken werden abgelehnt
